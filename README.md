# M3U8 视频下载器

Windows 下使用的交互式 M3U8 视频下载工具，支持慢速单连接和高速并发下载。

## 功能

- 直接粘贴 M3U8 或视频地址下载。
- 支持 `preview=video` 自动转换为 `preview=download`。
- 原域名不可访问时，自动尝试备用域名。
- 系统 DNS 解析失败时，自动使用公共 DNS 解析。
- 支持慢速单连接模式和高速并发连接模式。
- 支持设置并发连接数、进度刷新间隔和下载目录。
- 高速模式下按分片保存，中断后可继续下载。
- 使用 FFmpeg 合并分片并转封装为 MP4。

## 环境要求

- Windows 10/11
- PowerShell 7（推荐；脚本也可尝试使用 Windows PowerShell 5.1）
- FFmpeg
- curl

## 使用方法

1. 双击 `启动下载器.bat`。
2. 首次使用时进入设置，配置下载目录、下载模式和并发连接数。
3. 直接粘贴视频地址回车开始下载。
4. 下载完成后，MP4 会保存到设置的下载目录。

## 设置说明

- 下载输出地址：视频保存目录。
- 下载模式：
  - 慢速单连接模式：兼容性优先，使用单连接下载。
  - 高速并发连接模式：分片并发下载，推荐使用。
- 进度刷新间隔：控制进度条更新频率，单位为秒。
- 并发连接数：仅高速模式生效，推荐 8-16，最高支持 32。

## 说明

`config.json` 保存本机路径和设置，已加入 `.gitignore`，不会提交到 Git。

下载的视频、分片、日志和临时文件同样不会提交到 Git。

请仅下载和保存你有权访问的内容。
